# Irina: практические инструкции и доступ через SendPulse

## Продажи

Каждый раздел стоит **1 200 Telegram Stars**:
- Креативы -> `creatives`
- Инфраструктура Facebook Ads -> `infrastructure`
- Keitaro -> `keitaro`
- Запуск и анализ рекламы -> `launch`

Полный комплект: **3 600 Telegram Stars**.

Бот покупки: https://t.me/rstshelp_bot?start=6ad360e905eb22d6de058dac

## Теги доступа

В SendPulse **только после подтверждённого платежа** назначать следующие теги:

- `Практика: Креативы`
- `Практика: Инфраструктура`
- `Практика: Keitaro`
- `Практика: Запуск`
- `Практика: Все` для полного комплекта

Тег `Оплата` от основного обучения НЕ считается оплатой этих товаров.
Выбор кнопки продукта / переход по ссылке НЕ должен выдавать доступ.

**Важно:** Редактор цепочек и автоматическая выдача тега после платежа настраиваются в самом SendPulse. Этот репозиторий отвечает за проверку уже присвоенных тегов по Telegram ID.

## Архитектура

Контент 59 уроков хранится в отдельной базе **Cloudflare D1** `irina-miniapp-learning`, таблица `learning_lessons_v2`. Цена, ссылка оплаты и ассортимент находятся в `learning_settings`.

Worker `irina-learning-api` выдаёт публичные списки уроков и бесплатную теорию, а платные уроки только после проверки подписи Telegram и тегов пользователя через внутренний обработчик Vercel `/api/learning-authorize`. Фронтенд получает данные через `/api/learning`; Vercel не хранит тексты уроков.

Чтобы исправлять контент и цены, меняйте записи в Cloudflare D1, Vercel deployment не нужен.

## Проверки перед выпуском

1. /theory показывает 9 тем, каждый урок читается без оплаты.
2. /practice показывает 4 раздела (по 1 200 ⭐) и комплект (3 600 ⭐).
3. Пользователь без подписанных данных Telegram или без нужного тега получает 403 на платный урок.
4. Сегментированный доступ не распространяется на другие разделы.
5. Покупатель полного комплекта видит все четыре раздела.
6. Переход в SendPulse ведёт в цепочку «Выбор продутка»; в ней настроены реальные Telegram Stars платежи.
7. Кнопки «Назад» и «Домой» работают внутри Telegram Mini App и веб-версии.
8. Темы, ставки и контент можно менять без нового Vercel-деплоя.
