# Irina: учебные материалы

Бесплатная теория доступна без оплаты. Продажа практических инструкций и доступ к ним отключены; `/practice` показывает заглушку. `/api/learning-authorize` не выдаёт разрешения, Worker продолжает отклонять запросы к платным урокам. Содержимое уроков и медиа в Cloudflare сохранено. Интеграции с внешней CRM для авторизации больше нет.
